# 365 Day Box

一个本地运行的「365 天电子盲盒」MCP + Web 项目。

核心玩法：
- 每个日期最多一个盒子。
- MCP 可以创建、修改、查看、删除状态。
- 只有到达解锁日期，`open_box` 才会返回内容。
- 提示词 `prompt` 可选，主要用于给写盒子的 AI 提供创作方向。
- Web 页面显示 365 天日历、填充状态和当天盒子。
- SQLite 数据全部保存在本地。

## 环境

建议 Node.js 20+。

## 启动

在项目根目录：

```bash
npm install
npm run dev
```

启动后：
- Web: http://192.168.3.219:5173
- API: http://192.168.3.219:3001
- MCP: http://192.168.3.219/mcp

也可以分别启动：

```bash
npm run server
npm run web
```

首次启动会自动创建 SQLite 数据库。

## MCP

MCP 使用 Streamable HTTP。

工具：
- `create_box`：创建一个日期盒子
- `update_box`：修改尚未打开的盒子
- `delete_box`：永久删除指定日期的盒子；删除后该日期恢复为空盒，内容不可恢复
- `open_box`：打开指定日期，未到日期只返回锁定信息
- `today_box`：打开今天的盒子
- `calendar_status`：查看日期状态，不返回未来内容
- `next_empty_dates`：寻找空日期

### Operit / 其他 MCP 客户端

MCP Server 地址：

```text
http://192.168.3.219:3001/mcp
```

如果客户端要求完整 MCP URL，直接填写这个地址。

## 示例

创建：

```json
{
  "date": "2027-12-25",
  "prompt": "圣诞",
  "content": "给未来的你，圣诞快乐。"
}
```

提前打开：

```json
{
  "date": "2027-12-25"
}
```

会得到类似：

```json
{
  "locked": true,
  "date": "2027-12-25",
  "unlock_at": "2027-12-25T00:00:00+08:00"
}
```

到了日期才返回内容。

删除盒子时调用 `delete_box`：

```json
{
  "date": "2027-12-25"
}
```

这个操作会永久删除该日期的内容，成功后该日期会恢复为空盒。

## 关于安全

这是一个本地 MVP。未来盒子在 SQLite 中是本地明文保存的，因此它主要依赖 MCP 工具权限和业务逻辑防止正常调用提前读取。

如果以后想做「连数据库里都不能提前看到」的真正时间锁，可以在这个项目上继续加入加密和服务端密钥释放机制。
